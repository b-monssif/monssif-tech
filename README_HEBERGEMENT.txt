SITE PROFESSIONNEL — MONSSIF BOUDAOUD — VERSION 4

Ce dossier est un site statique prêt à héberger.

Fichiers principaux :
- index.html : page d'accueil
- styles.css : design et animations
- script.js : interactions et animations au scroll
- 404.html : page d'erreur
- robots.txt : indexation basique

Hébergement :
1. GitHub Pages : déposer les fichiers à la racine d'un dépôt puis activer Pages.
2. Netlify / Cloudflare Pages : glisser-déposer le dossier ou connecter le dépôt.
3. Hébergement classique : envoyer tous les fichiers dans le dossier public/www.
